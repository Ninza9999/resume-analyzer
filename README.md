# AI Resume Analyzer 🚀

## Overview
This is a full-stack AI-based Resume Analyzer that evaluates resumes and provides role-based insights.

## Features
- Upload PDF resumes
- Role-based analysis (enter job role)
- Skill extraction and missing skill detection
- Match percentage calculation
- AI-style summary and recommendations
- Interactive UI with animated background

## Tech Stack
- Backend: Flask (Python)
- Frontend: HTML, CSS, JavaScript
- Libraries: PyPDF2, Flask-CORS

## How to Run

### Backend
cd backend  
pip install -r requirements.txt  
python app.py  

### Frontend
Open home.html in browser

## Example Output
- Match: 70%
- Score: 7/10
- Skills: Python, Machine Learning
- Missing: SQL, Deployment
